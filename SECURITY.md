# Security Policy

## Supported versions

This repository maintains the latest version of its presentation materials,
scripts, and infrastructure definitions on the default branch.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability or exposed secret.

Use one of these private channels:

1. [GitHub Private Vulnerability Reporting](https://github.com/devkimchi/github-copilot-sandbox/security/advisories/new)
2. Email `enquiry (at) devkimchi (dot) com`

Include:

- A clear description of the issue
- Affected files or workflows
- Reproduction steps
- Potential impact
- Any suggested remediation

Reports will be acknowledged as soon as practical. Please allow time to
investigate and coordinate a fix before public disclosure.
